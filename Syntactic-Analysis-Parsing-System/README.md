# Syntactic Analysis Parsing System

## Assignment 7 - Parsing

A Natural Language Processing system that performs both **Constituency Parsing** and **Dependency Parsing** to discover grammatical relationships and syntactic structures in complex sentences.

---

## Objective

The objective of this project is to design a syntactic analysis system that can:

- Analyze the grammatical structure of sentences.
- Perform constituency parsing.
- Perform dependency parsing.
- Identify grammatical relationships between words.
- Display dependency relationships in tabular form.
- Generate dependency tree visualizations.
- Handle complex English sentences.

---

## Technologies Used

- Python 3
- spaCy
- NLTK
- NetworkX
- Matplotlib
- Pandas
